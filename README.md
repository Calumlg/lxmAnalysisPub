# lxmAnalysisPub
Repository containing data and code to reproduce analysis and figures from 'Effort choices are sensitive to prior learning'.
- Now contains html wrapped versions of the main and supplementary analysis files that has already run all the models and plotted the figures.

## How to use:
1. Download a ZIP of the repo to your desktop or another location of your choosing.
2. Use the .Rmd files in the data folder to replicate the main analysis and figures as well as the supplementary analysis

**NOTE** Supplementary Figure 6 is actually generated in the analysis and mainFigs .Rmd file because it depends on the winning 'mental health' model.
**NOTE** 3D bar plots are in standalone MATLAB code as (to my knowledge) you cannot generate equivalent plots in R.
